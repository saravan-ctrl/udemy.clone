# udemy.clone
A simple udemy clone website 
A simple Udemy Clone Website created using HTML5 and CSS3. This project was developed as a frontend practice project to recreate the basic layout and design of an online learning platform.

Technologies Used

- HTML5
- CSS3

Features

- Navigation Bar
- Search Bar
- Course Categories
- Course Cards
- Course Images
- Course Ratings and Prices
- Promotional Banner
- Footer Section
- Responsive Layout

What I Learned

This project helped me improve my understanding of:

- HTML page structure
- CSS styling
- Flexbox
- Responsive web design
- Website component design
- Basic frontend development

Project Status

Completed ✅

This project was created as a frontend practice project using HTML and CSS only.

Project Purpose

The main goal of this project is to practice frontend web development skills by recreating the layout and user interface of an online learning website
